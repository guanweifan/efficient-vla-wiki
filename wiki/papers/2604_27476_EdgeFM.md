## Claim
- 页面定位：这是一篇 **edge inference framework / cross-platform runtime** 论文；它不是 VLA-specific policy 方法，而是面向 VLM/LLM 以及 VLA deployment cases 的系统效率工作。
- EdgeFM 的核心设计是 thin runtime + heavy kernels：移除非必要 runtime 功能，使用 operator implementation table 和 agent-tuned kernels，为 edge single-request workloads 降低 latency。来源：[[raw/2604_27476_EdgeFM.pdf]]，Abstract、Figure 2、method section。
- 论文强调跨平台支持，包括 x86、NVIDIA Orin，以及 Horizon Journey platform，并把 SmolVLA deployment 作为 Horizon BPU 上的 VLA case。来源：[[raw/2604_27476_EdgeFM.pdf]]，Abstract、Figure 1、Section 4.3、Appendix B。
- headline 结果需要拆开理解：
  - Orin 上的 `1.49x` speedup 是相对 TensorRT-Edge-LLM 的 framework benchmark；
  - Horizon Journey 上的 VLA deployment 是系统可行性案例；
  - 论文主对象是 inference framework，不是新 VLA policy architecture。
- 更稳的主张是：EdgeFM 是 deployment-oriented efficiency 的边界条目，用来说明 runtime / kernel / hardware lock-in 也会成为 VLA 落地成本。
