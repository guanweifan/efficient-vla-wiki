## Claim
- 页面定位：这是一篇 **offline delay-robust post-training for asynchronous flow-matching VLA** 论文；它把部署时 latency 导致的 stale action 问题转成 label-free preference optimization。
- DEFLECT 从 frozen reference model 构造 fresh / stale counterfactual action pairs，并用 implicit flow-matching likelihood-ratio surrogate 给出 preference signal；训练后不增加额外 inference cost。来源：[[raw/2605_19294_DEFLECT.pdf]]，Abstract、Figure 2、Figure 3、Algorithm 1。
- 论文在 Kinetix、LIBERO / real-scale VLA setting 与真实机器人任务中分析 delay robustness，并报告 high-latency regime 与 longest-delay 条件下的收益。来源：[[raw/2605_19294_DEFLECT.pdf]]，Abstract、Table 1、Figures 4-5、Tables 4-6。
- 更稳的主张是：DEFLECT 是 deployment delay robustness / offline post-training 路线，不是减少 denoising NFE 的推理加速器。
