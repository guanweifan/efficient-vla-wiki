## Claim
- 页面定位：这是一篇 **VLA RL training compute allocation / gradient chunk masking** 论文；它把 GRPO-based VLA RL 的主要瓶颈定位到 actor-update gradient compute。
- PCM 用 success-failure action variance 作为 phase-level gradient variance proxy，并在 actor update 中只对少量 trajectory chunks 回传梯度，从而减少 wall-clock、gradient update 时间与 activation memory。来源：[[raw/2605_16154_PCM.pdf]]，Abstract、Figure 1、Figure 2、Algorithm 1。
- 论文在 LIBERO 上报告 2.38x wall-clock speedup、4.8x faster gradient updates、约 60% peak activation memory reduction，并指出 backprop 覆盖少于 20% trajectory chunks。来源：[[raw/2605_16154_PCM.pdf]]，Abstract、Figure 3、Table 1、Figure 4。
- 更稳的主张是：PCM 属于 training / RL gradient compute efficiency，不应被写成 inference-time action chunk skipping。

## 待核点
- PCM 的 chunk masking 发生在训练梯度更新中，不是部署时跳过动作执行。
- wall-clock speedup、gradient update speedup 与 memory reduction 是不同成本口径。
- variance proxy 不是显式 reward model 或 critic。
