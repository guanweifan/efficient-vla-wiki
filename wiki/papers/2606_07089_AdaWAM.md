## Claim
- 页面定位：这是一篇 **adaptive multimodal reasoning for World Action Models** 论文；它的核心效率问题是 WAM 不应始终做 video-action joint prediction，也不应始终 action-only，而应按执行上下文触发 textual / visual reasoning。
- AdaWAM 用动态 router 预测 `<TR>` 和 `<VR>` token：task transition 时触发 textual reasoning，fine-grained manipulation 时触发 visual reasoning，其余阶段默认 action-only decoding。来源：[[raw/2606_07089_AdaWAM.pdf]]，Abstract、Figure 1、Figure 3、method section。
- 论文通过 trajectory cues 和 VLM verification 构造 subtask-transition 与 fine-manipulation labels，用于监督 routing；这属于训练/标注机制，不应写成推理期额外人工输入。来源：[[raw/2606_07089_AdaWAM.pdf]]，Figure 2、method section。
- headline 结果应拆成 LIBERO / RoboTwin / real-world task performance 与 inference-time bubble analysis；adaptive reasoning 的收益是 task performance 与 unnecessary inference overhead 的折中。来源：[[raw/2606_07089_AdaWAM.pdf]]，Table 1、Table 2、Table 3、Figure 6、Table 4。

## 待核点
- AdaWAM 的 efficiency 是 adaptive reasoning overhead control；不能只按 raw latency 与 action-only WAM 比优劣。
- Text reasoning、visual reasoning 与 action-only decoding 是互补 modes；比较时需要说明触发上下文。
- 本篇是 WAM route，不是传统 VLA CoT-only reasoning route。
