## Claim
- 页面定位：这是一篇 **differentiable visual-token resampling / task-aware visual bandwidth** 论文；它把 VLA 中冗余视觉 token 的处理从离散丢弃改为连续坐标采样。
- GridS 预测 salient coordinates，并用 differentiable interpolation 从视觉特征图中重采样少量 task-aware tokens；论文强调在少于 10% 原始视觉 tokens 时保持任务表现，并报告约 76% FLOPs reduction。来源：[[raw/2605_11817_GridS.pdf]]，Abstract、Figure 1、Figure 3。
- 论文将 GridS 作为 plug-and-play 模块接入 π0、π0.5 与 SmolVLA，并在 LIBERO、ALOHA、real robot、LIBERO-PLUS、RoboTwin 等设置中评估。来源：[[raw/2605_11817_GridS.pdf]]，Abstract、Figure 1、method / experiment sections。
- 更稳的主张是：GridS 属于 visual bandwidth / token selection 路线，但它的机制是 differentiable grid sampling，不应与硬阈值 token drop 简化为同一类。

## 待核点
- “少于 10% tokens”是 visual token retention 口径，不应直接等同于端到端控制频率。
- GridS 的核心是连续重采样，不应写成普通 semantic-only pruning。
- 不同 backbone 与 benchmark 的 retention / success / latency 结果需要分开读。
