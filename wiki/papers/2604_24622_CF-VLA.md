## Claim
- 页面定位：这是一篇 **coarse-to-fine flow-based action generation** 论文；它的核心效率问题是 flow-based VLA 从 Gaussian noise 多步恢复 action structure 的低效。
- CF-VLA 把 action generation 分成 coarse initialization 和 fine refinement 两段：coarse stage 学习 endpoint velocity posterior，把 Gaussian noise 转成 AP-guided initialization；fine stage 对该 initialization 做 single-step local correction。来源：[[raw/2604_24622_CF-VLA.pdf]]，Abstract、Figure 1、Figure 2、method section。
- 论文通过 stepwise training 先稳定 coarse predictor，再进入 joint coarse-to-fine optimization，以避免早期 coarse output 质量不足影响 refinement branch。来源：[[raw/2604_24622_CF-VLA.pdf]]，Figure 2、Algorithm 1、method section。
- headline 结果需要拆开理解：
  - `NFE=2` 是 action sampling / flow evaluation budget；
  - `75.4%` 是 action sampling latency reduction 口径；
  - LIBERO / CALVIN / real-robot success 是 task performance 口径。
- 更稳的主张是：CF-VLA 是 action-generation efficiency 的典型新增例子，说明低 NFE 不只是缩短 solver，还可以通过重构 starting point 来改变采样负担。

## 待核点
- CF-VLA 的效率主张应回到 action sampling latency / NFE 口径，不应写成整体机器人系统端到端部署 latency。
- 该方法作用于 flow-based VLA action expert；不能直接外推到 autoregressive action tokenizers。
- 真实机器人结果与 simulation NFE / latency 结果需要分层阅读。
