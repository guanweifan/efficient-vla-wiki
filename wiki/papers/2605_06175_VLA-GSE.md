## Claim
- 页面定位：这是一篇 **parameter-efficient VLA fine-tuning / generalized-specialized experts** 论文；它的核心效率问题是如何在固定 trainable-parameter budget 下增强 VLM-to-VLA adaptation。
- VLA-GSE 从 frozen backbone weight 的 SVD 初始化 generalized expert 和 specialized experts：leading singular components 分配给 always-on generalized expert，disjoint residual components 分配给 routed specialized experts。来源：[[raw/2605_06175_VLA-GSE.pdf]]，Abstract、Figure 1、Section 3.1。
- 方法还引入 expert-wise gradient scale balancing 和 backbone weight adjustment，用来缓解 spectral imbalance 与 initialization-time backbone drift。来源：[[raw/2605_06175_VLA-GSE.pdf]]，Section 3.2、Section 3.3、Algorithm 1。
- headline 结果需要拆开理解：
  - `2.51%` 是 trainable-parameter ratio；
  - LIBERO-Plus / standard LIBERO 是 simulation control benchmark；
  - multimodal benchmark 是 VLM knowledge preservation 口径；
  - real-world results 是 distribution shift 下的 manipulation evaluation。
- 更稳的主张是：VLA-GSE 是 PEFT-for-VLA adaptation efficiency 的新增证据，强调“少量可训练参数 + 更强控制适配 + 保留 VLM 能力”的三者折中。
