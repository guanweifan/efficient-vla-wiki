## Claim
- 页面定位：这是一篇 **block diffusion action generation / AR-to-diffusion VLA adaptation** 论文；它通过 block-level causal dependency 与 block-internal parallel denoising 压缩 discrete diffusion policy 的推理成本。
- BlockVLA 将 pretrained autoregressive backbone 改造成 block diffusion policy，保留 block 间 AR dependency，同时在 block 内并行 denoise，并复用已完成 block 的 prefix KV-cache。来源：[[raw/2605_13382_BlockVLA.pdf]]，Abstract、Figure 1、Table 1。
- 论文在 LIBERO 与 SimplerEnv 上评估，并报告相对标准 discrete diffusion VLA 的 3.3x inference acceleration，以及更平滑的 AR-to-diffusion fine-tuning / training convergence。来源：[[raw/2605_13382_BlockVLA.pdf]]，Abstract、Figure 1、experiment sections。
- 更稳的主张是：BlockVLA 位于 action-generation decoding compression 与 train-to-infer bridge 的交界；KV-cache reuse 是 action block 结构的一部分，不等于 perception temporal cache。

## 待核点
- 3.3x acceleration 是相对 discrete diffusion setting 的推理口径，不能直接和 token pruning speedup 并表。
- KV-cache reuse 发生在 action block decoding 中，不应写成跨帧视觉缓存。
- 训练收敛收益与推理加速应分层记录。
