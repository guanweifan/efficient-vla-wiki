## Claim
- 页面定位：这是一篇 **adaptive test-time compute / reasoning-aware action selection** 论文；它的核心问题是 VLA 在困难或歧义场景中何时从 reflexive execution 切换到 deliberation。
- VLA-ATTC 用 uncertainty-based cognitive clutch 判断是否触发 TTC deliberation；在 TTC 阶段生成多个 action candidates，再用 Relative Action Critic (RAC) 通过 pairwise comparison 选择更优动作。来源：[[raw/2605_01194_VLA-ATTC.pdf]]，Abstract、Figure 2、Figure 3、Algorithm 1。
- RAC 不直接学习绝对 action value，而是学习 action pair preference；论文还设计 automated preference-pair curation pipeline 和 efficient sampling strategy 来降低 TTC 成本。来源：[[raw/2605_01194_VLA-ATTC.pdf]]，Abstract、Figure 4、method section。
- headline 结果需要拆开理解：
  - LIBERO-LONG failure-rate reduction 是 simulation benchmark 口径；
  - real-world success improvement 是 Agilex Piper task 口径；
  - control frequency 结果说明 adaptive trigger 限制了 always-on deliberation 的成本。
- 更稳的主张是：VLA-ATTC 是 reasoning efficiency 与 inference-time dynamic compute allocation 的交界例子，重点是按 uncertainty 选择何时 deliberation，而不是减少 action denoising steps。
