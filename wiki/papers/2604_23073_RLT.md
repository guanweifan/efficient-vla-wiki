## Claim
- 页面定位：这是一篇 **RL-token interface / online RL adaptation** 论文；它的核心效率来源是让轻量 actor-critic 在 pretrained VLA 的 compact representation 上做 sample-efficient online RL，而不是直接压缩 VLA 推理路径。
- RLT 通过训练 encoder-decoder 让 VLA 暴露一个 RL token，再用该 token 和 VLA reference action chunk 训练小型 actor / critic；在线 RL 过程还用 regularizer 将 actor 锚定到 VLA 动作附近。来源：[[raw/2604_23073_RLT.pdf]]，Abstract、Figure 1、Figure 2、method section。
- 论文把实验集中在 screw installation、zip tie fastening、Ethernet insertion、charger insertion 等 real-robot precision-critical phases，并报告几分钟到几小时的在线练习后，critical phase 的 speed 和 success rate 有改善。来源：[[raw/2604_23073_RLT.pdf]]，Abstract、Figure 3、experiment section。
- headline 结果需要拆开理解：
  - `up to 3x` 是 critical phase execution speed / throughput 口径；
  - success rate 提升是 real-robot task outcome 口径；
  - online RL sample efficiency 依赖 small actor-critic、RL token、action chunk 与 VLA anchoring 的组合。
- 更稳的主张是：RLT 是 VLA adaptation efficiency 的新增路线，把大 VLA 保留为 representation / behavior prior，再把任务特化交给轻量 online RL。

## 待核点

- RLT 使用的 VLA base policy 和 RL actor-critic 组合需要和 full-model RL / residual policy 路线分开读。
- 当前页面未展开每个 real-robot task 的具体成功率表述；如需做 metric evidence，应继续拆 Figure 4-9。
