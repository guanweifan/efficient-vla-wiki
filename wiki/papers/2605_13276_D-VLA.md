## Claim
- 页面定位：这是一篇 **distributed RL training system for VLA / high-concurrency training pipeline** 论文；它把效率瓶颈放在大规模 embodied RL 训练的采样、推理、梯度和参数分发并行化上。
- D-VLA 使用 Plane Decoupling 将高频训练数据与低频权重控制物理隔离，并用四线程异步 Swimlane pipeline 重叠 sampling、inference、gradient computation 与 parameter distribution。来源：[[raw/2605_13276_D-VLA.pdf]]，Abstract、Figure 2。
- 论文还引入 dual-pool VRAM management 与 topology-aware replication，并在 π0.5 / OpenVLA-OFT 等 setting 中报告 throughput、success rate 与 scaling 分析。来源：[[raw/2605_13276_D-VLA.pdf]]，Abstract、Figure 3、Table 1、Figures 4-7。
- 更稳的主张是：D-VLA 属于 training-system / RL throughput 路线；其中的 asynchronous inference 服务训练流水线，不应直接写成 deployment-time async VLA 方法。

## 待核点
- 该文的 primary cost 是训练系统吞吐，不是单步 inference latency。
- 与 deployment-oriented async control 比较时，需要保留 training pipeline 与 online control loop 的边界。
- scalability 结果依赖硬件、worker placement 与 environment count，不能抽象成通用 VLA 性能提升。
