## Claim
- 页面定位：这是一篇 **world-module visual bandwidth compression / latent rollout coupling** 论文；它的核心效率问题是 world-model-augmented VLA 在 long horizon 下每帧高视觉带宽带来的 token/memory 成本。
- OneWM-VLA 通过 Adaptive Attention Pooling 把每个 view 每帧压缩成单个 semantic latent token，并用 joint flow-matching objective 同时生成 future latent stream 与 action trajectory。来源：[[raw/2605_07931_OneWM-VLA.pdf]]，Abstract、Figure 1、Figure 2、Section 4。
- 论文在 π0 backbone 上用 LoRA 训练，并报告只增加 14.71M trainable parameters；推理时只执行 action branch，latent tokens 作为 internal auxiliary trajectory 结构化 action generation。来源：[[raw/2605_07931_OneWM-VLA.pdf]]，Abstract、Introduction、method section。
- headline 结果需要拆开理解：
  - MetaWorld MT50、LIBERO-Long、real Piper Fold Cloth 是不同 evaluation settings；
  - per-frame token sweep 用于支撑“1 token per frame”设计判断；
  - throughput / memory 表是 world-module visual bandwidth 的资源口径，不是完整机器人系统 latency。
- 更稳的主张是：OneWM-VLA 是 selective feature / representation efficiency 的边界例子，把视觉 token compression 从 policy perception 扩展到 auxiliary world-module rollout。

## 待核点
- OneWM-VLA 的 single-token conclusion 是在 frozen/pretrained VLA + LoRA adaptation setup 下得到的，不能写成所有 world models 只需 1 token。
- 论文的效率收益主要是 world-module bandwidth / horizon scalability，不是直接减少 action denoising steps。
- 如后续写 visual token efficiency，应标注它与 VLA policy perception token pruning 的边界。
