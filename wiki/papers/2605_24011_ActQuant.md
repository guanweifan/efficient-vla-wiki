## Claim
- 页面定位：这是一篇 **action-guided sub-4-bit PTQ and native runtime deployment** 论文；它的核心效率问题是把 VLA backbone 压到低比特并在实际 runtime 中兑现 memory / latency 收益。
- ActQuant 由 inter-tensor bit allocation 与 intra-tensor scale optimization 两段组成，两个阶段都用 action relevance / action-aware curvature 指导量化，而不是只按 language-model proxy 做 PTQ。来源：[[raw/2605_24011_ActQuant.pdf]]，Abstract、Introduction、method section。
- 论文同时提出 OmniModel.cpp，用 agentic conversion pipeline 把 PyTorch VLA 转成 native C/C++ inference build，并使用低比特 kernels 支撑 on-device deployment。来源：[[raw/2605_24011_ActQuant.pdf]]，Abstract、Figure 4。
- headline 结果需要拆开：LIBERO success retention、backbone memory compression、OpenVLA per-token latency、UR3 real-world success 分别属于不同口径。来源：[[raw/2605_24011_ActQuant.pdf]]，Figure 1、Table 2、Table 3、Table 4。

## 待核点
- ActQuant 的 latency claim 绑定 OmniModel.cpp runtime 与具体 hardware；不能只把 PTQ method 本身写成天然加速。
- `sub-4-bit` 结果主要是 weight quantization / backbone compression 口径；和 full-stack W4A4 action-head quantization 需要与 Omega-QVLA 分开。
- UR3 实验是 physical robot deployment evidence，但 task set 与 LIBERO simulation 不能并表成统一成功率。
